# Physical Evaluation Protocol Calibration v1.0

Ticket #057 adds a read-only interpretation layer over immutable standalone physical-evaluation evidence. It distinguishes disagreement about the same dimension from stable divergence between dimensions that may represent different physical constructs.

The layer reports transparent distributions, modes, adjacent support, possible outlier observations, and cross-dimension divergence. Possible outliers are diagnostic only: observations and evaluator identity remain intact and are never excluded automatically.

Sweet-spot breadth (`usable_contact_region`) is analyzed separately from response quality (`centered_response_consistency` and `near_center_response_consistency`). Forgiveness retains handle-side and end-side miss asymmetry, while `response_degradation` remains inverse. Swing effort recommends consistent warm-up and multiple swing blocks when protocol sensitivity persists. Bat-control comparisons remain corroborating and non-dispositive when the reference is not an approved canonical anchor.

After five independent qualifying evaluators, persistent material disagreement triggers protocol or construct review before another general evaluator is requested. Targeted evidence can follow a reviewed protocol. The current protocol and registry are unchanged; any construct split is a proposal for a future version.

This analysis creates no canonical evaluations, numeric references, recommendation inputs, or database writes.
